# Estoque da galera 📦

Coloque aqui imagens de memes (`.jpg`, `.jpeg`, `.png`, `.gif` ou `.webp`, até 10 MB cada).

- De vez em quando (20% das vezes, ajustável no `config.yml`) o bot posta um meme daqui em vez do Reddit.
- Se o Reddit falhar, o estoque vira o plano B.
- Cada arquivo sai **uma vez só**. Para repetir um meme, suba com outro nome.

Como subir pelo site do GitHub: abra esta pasta → **Add file** → **Upload files** → arraste as imagens → **Commit changes**.
